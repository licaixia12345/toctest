# 贪吃蛇游戏 PRD

## 1. 产品概述

一款具有现代视觉设计的经典贪吃蛇网页游戏，融合霓虹赛博朋克美学风格，为玩家提供沉浸式的游戏体验。

- **核心目标**：打造一款视觉惊艳、操作流畅的贪吃蛇游戏，让经典玩法焕发新生
- **目标用户**：休闲游戏玩家、怀旧游戏爱好者、追求视觉体验的用户

## 2. 核心功能

### 2.1 功能模块

1. **游戏主界面**：游戏画布、分数显示、控制按钮、游戏状态指示
2. **开始界面**：游戏标题、开始按钮、最高分记录、游戏说明

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 开始界面 | 游戏标题 | 霓虹风格的动态标题动画 |
| 开始界面 | 开始按钮 | 点击进入游戏，带有脉冲动画效果 |
| 开始界面 | 最高分记录 | 显示历史最高分数 |
| 开始界面 | 游戏说明 | 简洁的操作指引（键盘方向键/WASD控制） |
| 游戏主界面 | 游戏画布 | 蛇身移动、食物生成、碰撞检测的渲染区域 |
| 游戏主界面 | 分数面板 | 实时显示当前分数、当前长度 |
| 游戏主界面 | 暂停/继续按钮 | 游戏暂停与恢复功能 |
| 游戏主界面 | 游戏结束弹窗 | 显示最终分数、重新开始按钮、返回主菜单按钮 |

### 2.3 游戏规则

- 蛇初始长度为3节，从画布中央开始
- 使用方向键或WASD控制蛇的移动方向
- 吃到食物后蛇身增长1节，分数增加
- 撞墙或撞到自身则游戏结束
- 随着分数增加，蛇的移动速度逐渐加快

## 3. 核心流程

### 3.1 游戏主流程

用户打开游戏 → 显示开始界面 → 点击开始按钮 → 进入游戏 → 控制蛇移动吃食物 → 游戏结束 → 显示结算界面 → 选择重新开始或返回主菜单

## 4. 用户界面设计

### 4.1 设计风格

- **主题风格**：霓虹赛博朋克风格，深色背景配合发光效果
- **主色调**：深紫黑色背景 (#0a0a0f)，霓虹青色 (#00fff7) 作为主强调色，霓虹粉色 (#ff00ff) 作为次强调色
- **蛇身设计**：渐变色蛇身，头部发光效果，身体带有流光动画
- **食物设计**：脉动发光的几何图形
- **按钮风格**：圆角矩形，带有霓虹边框发光效果，hover时增强发光
- **字体**：使用 Orbitron 作为标题字体（科技感），Rajdhani 作为正文字体
- **布局**：居中布局，游戏画布居中显示，信息面板在画布上方

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 开始界面 | 游戏标题 | Orbitron字体，霓虹发光效果，轻微浮动动画 |
| 开始界面 | 开始按钮 | 霓虹边框，脉冲动画，hover时发光增强 |
| 开始界面 | 最高分记录 | 小型数字显示，金色发光效果 |
| 游戏主界面 | 游戏画布 | 600x600像素，网格背景，边框发光 |
| 游戏主界面 | 分数面板 | 左上角显示当前分数，数字动态增长动画 |
| 游戏主界面 | 暂停按钮 | 右上角，半透明背景，霓虹图标 |
| 游戏主界面 | 游戏结束弹窗 | 居中半透明遮罩，显示分数和按钮 |

### 4.3 响应式设计

- 采用桌面优先设计，游戏画布固定尺寸
- 移动端适配：画布缩放至屏幕适配，支持触摸滑动控制
- 平板端：保持桌面布局，支持触摸和键盘双控制

### 4.4 动效设计

- **蛇移动**：平滑过渡动画，身体跟随效果
- **食物出现**：缩放弹跳动画
- **吃到食物**：蛇身闪光效果，分数跳动动画
- **游戏结束**：画面震动效果，淡出动画
- **背景**：缓慢流动的网格线，营造科技感氛围

## 5. 技术要点

### 5.1 性能要求

- 游戏帧率稳定在60fps
- 蛇移动响应延迟 < 50ms
- 首屏加载时间 < 2s

### 5.2 数据存储

- 使用 localStorage 存储最高分记录
- 游戏状态自动保存（暂停时）

### 5.3 兼容性

- 支持主流现代浏览器（Chrome、Firefox、Safari、Edge）
- 支持键盘和触摸屏操作
