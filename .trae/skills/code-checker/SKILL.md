# Code Checker

检查并修复工作区中的代码问题。

## 参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| 参数1 | `check` | 检查工作区代码存在的问题 |
| 参数1 | `fix` | 修复工作区代码存在的问题 |

## 使用方法

### 检查代码问题
当用户输入类似以下内容时使用：
- "检查代码问题"
- "check 代码"
- "帮我检查下代码"

### 修复代码问题
当用户输入类似以下内容时使用：
- "修复代码问题"
- "fix 代码"
- "帮我修复下代码"

## 执行步骤

### Check 模式
1. 运行 TypeScript 类型检查：`npm run check`
2. 运行 ESLint 代码检查：`npm run lint`
3. 收集所有错误和警告
4. 生成问题报告，包括：
   - 问题文件路径
   - 问题类型（TS 错误 / ESLint 警告）
   - 问题描述
   - 所在行号

### Fix 模式
1. 运行 TypeScript 类型检查确认问题
2. 运行 ESLint 自动修复：`npx eslint . --fix`
3. 检查是否还有其他可自动修复的问题
4. 报告修复结果

## 注意事项

- 只处理 TypeScript 和 JavaScript 文件
- 优先使用 ESLint 的自动修复功能
- 对于无法自动修复的问题，需要手动处理
