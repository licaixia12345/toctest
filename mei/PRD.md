# 美丽修行小游戏 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
美丽修行 (Beauty Cultivation)

### 1.2 产品定位
一款轻松休闲的护肤养成类小游戏，玩家通过日常护肤步骤的模拟，体验从护肤新手到美容达人的成长过程。

### 1.3 目标用户
- 对护肤美容感兴趣的用户
- 喜欢轻松休闲游戏的玩家
- 15-35 岁年龄段，女性用户为主

## 2. 核心功能

### 2.1 游戏主界面
- 展示玩家角色形象
- 显示当前肌肤状态（水分、光泽度、弹性等指标）
- 显示游戏货币和等级

### 2.2 护肤系统
- **清洁**: 洁面步骤，去除污垢
- **补水**: 使用化妆水、精华液
- **保湿**: 涂抹乳液、面霜
- **防晒**: 日间防护步骤
- **特殊护理**: 面膜、去角质等

### 2.3 产品收集系统
- 收集各种护肤品（洁面乳、爽肤水、精华、面霜等）
- 不同品质的护肤品效果不同
- 可通过游戏货币购买或完成任务获得

### 2.4 任务系统
- 每日任务：完成日常护肤流程
- 成就任务：达到特定肌肤状态指标
- 收集任务：收集指定数量的护肤品

### 2.5 肌肤状态系统
- **水分值**: 影响肌肤饱满度
- **光泽度**: 影响肌肤明亮程度
- **弹性值**: 影响肌肤紧致度
- **清洁度**: 影响肌肤健康状态

### 2.6 商店系统
- 购买护肤品
- 解锁新的护肤步骤
- 装饰个人空间

## 3. 游戏机制

### 3.1 时间系统
- 游戏内分为早晨和夜晚两个时段
- 不同时段有不同的护肤流程
- 某些护肤品只能在特定时段使用

### 3.2 能量系统
- 每次护肤操作消耗能量
- 能量随时间自然恢复
- 可通过休息或使用道具恢复能量

### 3.3 等级系统
- 玩家通过完成护肤任务获得经验值
- 升级解锁新的护肤步骤和产品
- 等级影响可购买的护肤品品质

### 3.4 货币系统
- **金币**: 基础货币，通过日常任务获得
- **钻石**: 高级货币，通过成就或特殊活动获得

## 4. 界面设计

### 4.1 视觉风格
- 清新、柔和的粉色系主色调
- 圆润可爱的 UI 元素
- 精美的护肤品图标和动画效果

### 4.2 主要界面
1. **主界面**: 角色展示、状态面板、快捷入口
2. **护肤界面**: 护肤步骤操作区域
3. **背包界面**: 护肤品展示和管理
4. **商店界面**: 商品浏览和购买
5. **任务界面**: 任务列表和奖励领取

## 5. 技术要求

### 5.1 技术栈
- 前端框架：React + TypeScript
- 构建工具：Vite
- 样式方案：Tailwind CSS
- 状态管理：React Hooks
- 动画效果：CSS Animations + Framer Motion

### 5.2 性能要求
- 首屏加载时间 < 2 秒
- 动画帧率保持 60fps
- 支持移动端和桌面端响应式布局

### 5.3 兼容性
- 支持主流现代浏览器（Chrome、Firefox、Safari、Edge）
- 移动端支持 iOS Safari 和 Android Chrome

## 6. 游戏流程

### 6.1 新手引导
1. 创建角色形象
2. 学习基础护肤步骤
3. 完成第一次完整护肤流程
4. 解锁商店和任务系统

### 6.2 日常游戏循环
1. 登录游戏，领取每日签到奖励
2. 完成早晚护肤流程
3. 完成每日任务
4. 收集和使用新护肤品
5. 提升肌肤状态指标

### 6.3 长期目标
- 所有肌肤指标达到满分
- 收集全部护肤品
- 解锁所有成就
- 达到最高等级
